Historia de Linux

Linux no nació como un proyecto corporativo ni como una startup Silicon Valley. Nació como un hobby de un estudiante finlandés que quería algo diferente. Hoy, Linux ejecuta el 96% de los servidores del mundo, el 100% de los supercomputadores, el 72% de los smartphones y prácticamente todos los dispositivos embebidos del planeta.

01 Los orígenes — de UNIX a Linux

La historia de Linux comienza décadas antes de que Linus Torvalds escribiera la primera línea de código. Es una historia de revolución tecnológica, filosofía del software libre y colaboración global.

1969 — UNIX en Bell Labs

El nacimiento de UNIX

Dennis Ritchie y Ken Thompson crearon UNIX en los laboratorios Bell de AT&T. Originalmente escrito en ensamblador, fue reescrito en C por Ritchie, convirtiéndose en el primer sistema operativo portáble. UNIX introdujo conceptos revolucionarios que siguen vigentes: la jerarquía de archivos (todo es un archivo), los permisos de usuario, la separación de espacio de usuario y kernel, y la filosofía de hacer una sola cosa y hacerla bien.

UNIX influyó en todos los sistemas operativos modernos: BSD, System V, y eventualmente Linux. Sin UNIX, la computación actual sería irreconocible.

1983 — El Proyecto GNU

Richard Stallman y la revolución del software libre

Richard Stallman, programador del MIT, lanzó el Proyecto GNU con una visión ambiciosa: crear un sistema operativo completamente libre, donde los usuarios pudieran ejecutar, copiar, distribuir, estudiar, modificar y mejorar el software. Creó la Free Software Foundation (FSF) y las licencias GPL.

GNU creó herramientas fundamentales: GCC (compilador), Emacs (editor), Bash (shell) y la mayoría de las utilidades básicas. Pero le faltaba un componente crítico: el kernel. GNU Hurd, el kernel planeado, nunca se completó de forma estable.

1991 — Linus Torvalds

El mensaje que cambió todo

Linus Torvalds, un estudiante de 21 años de la Universidad de Helsinki, publicó un mensaje en el grupo de noticias comp.os.minix:

"Estoy haciendo un sistema operativo (gratuito)... solo un hobby, nada grande y profesional."

Ese "hobby" se convirtió en el kernel Linux. Torvalds publicó el código fuente bajo la licencia GPL, permitiendo que cualquiera lo usara, lo modificara y lo distribuyera. En pocos años, miles de programadores de todo el mundo contribuyeron al proyecto.

1992–1994 — La fusión GNU/Linux

El sistema completo llega

Las herramientas GNU combinadas con el kernel Linux crearon el primer sistema operativo completo, libre y gratuito. Las primeras distribuciones nacieron: Slackware (1993) priorizaba la simplicidad, Debian (1993) se enfocaba en la estabilidad y la comunidad, y Red Hat (1994) apostaba por la facilidad de uso empresarial.

En 1994 se lanzó Linux 1.0 con soporte de red, marcando el inicio de la era de los servidores Linux. Lo que comenzó como un proyecto universitario se estaba convirtiendo en una fuerza tecnológica imparable.

2004 — Ubuntu llega al escritorio

Linux para todos

Canonical lanzó Ubuntu, una distribución basada en Debian pero diseñada para usuarios no técnicos. Con instalación en 20 minutos, escritorio gráfico intuitivo y comunidad activa, Ubuntu rompió la barrera de entrada de Linux. En pocos años se convirtió en la distribución más popular del mundo.

Ubuntu demostró que Linux no era solo para "hackers" y programadores. Puede ser elegante, fácil de usar y cotidiano. Esto abrió las puertas para que millones de personas conocieran Linux por primera vez.

02 Familias de distribuciones

No todas las distribuciones son iguales. Existen grandes familias que comparten gestores de paquetes, filosofías de diseño y objetivos de usuario. Conocer estas familias te permite entender rápidamente cualquier distribución.

🔴

Debian

La madre de muchas distribuciones. Conocida por su estabilidad extrema y su gestor de paquetes apt. Debian es 100% comunitaria: no tiene empresa detrás, lo que garantiza independencia. Es el sistema preferido para servidores de producción donde la confiabilidad es crítica. Las actualizaciones son conservadoras pero probadas exhaustivamente.

Ubuntu Linux Mint Kali Linux Raspberry Pi OS Deepin
🔵

Red Hat / Fedora

La familia empresarial por excelencia. Usa dnf (anteriormente yum) y gestiona paquetes RPM. Red Hat Enterprise Linux (RHEL) es el estándar en entornos corporativos con soporte comercial. Fedora es la versión comunitaria que prueba nuevas tecnologías antes de que lleguen a RHEL.

Fedora CentOS Stream AlmaLinux Rocky Linux
🟡

Arch Linux

Para usuarios avanzados que quieren control total. Rolling release con el gestor pacman. Filosofía KISS (Keep It Simple, Stupid): configuración manual,-documentación exhaustiva en el Arch Wiki (la mejor documentación de Linux), y las últimas versiones de todo el software. No hay versión "estable" como tal, cada actualización es la última.

Manjaro EndeavourOS Garuda Linux ArcoLinux
🟢

SUSE / openSUSE

De origen europeo (Alemania), muy popular en ese continente. Usa zypper como gestor de paquetes y formatos RPM. openSUSE Leap es la versión estable basada en el código de SUSE Linux Enterprise. Tumbleweed es la versión rolling release con actualizaciones frecuentes pero bien probadas.

openSUSE Leap openSUSE Tumbleweed SLES

03 Linux embebido y móvil

Linux domina el mundo de los dispositivos embebidos. Su flexibilidad, bajo consumo de recursos y licencia GPL lo hacen ideal para hardware especializado con recursos limitados.

📱 Android

El sistema operativo móvil más popular del mundo está basado en una versión modificada del kernel de Linux. Más del 72% de los smartphones del planeta ejecutan Android. Google compró Android Inc. en 2005 y lanzó la primera versión en 2008. Aunque utiliza el kernel de Linux, Android no es una distribución Linux convencional: tiene su propio ecosistema de aplicaciones, su propio gestor de paquetes (APK) y una capa de abstracción (ART) que lo hace diferente de Linux de escritorio.

🍓 Raspberry Pi

Esta mini computadora de $35 utiliza Raspberry Pi OS (basado en Debian) como sistema operativo principal. Desde su lanzamiento en 2012, se han vendido más de 60 millones de unidades. Es la puerta de entrada perfecta para aprender administración de sistemas, programación, electrónica y proyectos IoT. Su bajo consumo de energía y tamaño compacto lo hacen ideal para servidores domésticos, centros multimedia y domótica.

📺 Smart TVs y IoT

Los televisores inteligentes ejecutan versiones de Android TV o webOS basadas en Linux. Los routers domésticos (con OpenWrt o DD-WRT), las cámaras de seguridad, los asistentes inteligentes, los coches eléctricos y los dispositivos médicos: todos ejecutan versiones embebidas de Linux optimizadas para hardware con recursos muy limitados.

04 Linux en la nube

El 96% de los servidores web del mundo y el 100% de los supercomputadores Top500 funcionan sobre Linux. Cada vez que usas una aplicación móvil, visitas un sitio web o haces una transacción bancaria, es casi seguro que Linux está trabajando en algún servidor remoto.

☁

AWS / EC2

Amazon Web Services usa predominantemente Amazon Linux (basado en RHEL) y Ubuntu para sus instancias EC2. El 92% de las máquinas virtuales de AWS ejecutan alguna variante de Linux.

☁

Google Cloud

Google Cloud está optimizado para Debian y sus derivados. Google además desarrollacontainer-optimized OS (COS) para ejecutar contenedores Docker de forma segura.

☁

Microsoft Azure

Microsoft, que alguna vez llamó a Linux "un cáncer", ahora usa Ubuntu como distribución preferida en Azure. Más del 50% de las VMs de Azure ejecutan Linux.

🐳

Docker / Kubernetes

Los contenedores Docker revolucionaron el despliegue de aplicaciones. Kubernetes, el orquestador de contenedores, está construido sobre Linux. El 95% de los contenedores en producción ejecutan Linux.
