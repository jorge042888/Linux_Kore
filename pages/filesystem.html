El Filesystem de Linux

En Linux, todo es un archivo. Los dispositivos, los procesos, la configuración del sistema: todo se representa como un nodo en una estructura jerárquica de árboles. Comprender esta estructura es fundamental para cualquier administrador o usuario del sistema.

01 Árbol FHS interactivo

El Filesystem Hierarchy Standard (FHS) es el estándar que define la estructura de directorios en sistemas Linux. Especifica qué tipo de archivos debe encontrarse en cada directorio del sistema. Esto garantiza que los usuarios y administradores puedan encontrar los archivos que necesitan sin importar qué distribución estén usando.

📂

Selecciona un directorio para ver su descripción

02 Tipos de archivos

Linux reconoce varios tipos de archivos, cada uno con un propósito diferente. El primer carácter del resultado de ls -l indica el tipo de archivo. Conocer estas diferencias es esencial para entender cómo el sistema opera y cómo administrar los recursos correctamente.

📄

Archivos regulares

Contienen datos: texto, imágenes, binarios, documentos, cualquier información que el usuario o el sistema necesite almacenar. Es el tipo más común del sistema. Pueden contener datos estructurados como bases de datos, código fuente o simplemente notas de texto.

-rw-r--r-- 1 usuario usuario 4096 ene 15 10:30 documento.txt
📁

Directorios

Contienen otros archivos y directorios formando la estructura jerárquica. Cada directorio puede contener una cantidad ilimitada de entradas. Los directorios vacíos todavía ocupan un bloque en disco y contienen las entradas especiales . (actual) y .. (padre).

drwxr-xr-x 2 usuario usuario 4096 ene 15 10:30 documentos/
🔗

Enlaces simbólicos

Punteros que referencian otro archivo por su ruta. Si el archivo original se elimina o mueve, el enlace se rompe (queda apuntando a nada). Son extremadamente útiles para crear accesos directos o mantener versiones de archivos de configuración sin modificar el original.

lrwxrwxrwx 1 usuario usuario 18 ene 15 10:30 config -> /etc/app/config.conf
⚙

Dispositivos de bloque

Representan hardware de almacenamiento como discos duros (/dev/sda), discos SSD (/dev/nvme0n1) y dispositivos USB. Se accede a ellos por bloques de datos de tamaño fijo. Cada partición del disco tiene su propio archivo de dispositivo.

brw-rw---- 1 root disk 8, 0 ene 15 10:30 /dev/sda
📦

Archivos de socket

Puntos de comunicación entre procesos (IPC). Permiten que dos procesos se comuniquen en tiempo real a través de la red o localmente. Son fundamentales para servicios como bases de datos PostgreSQL, servidores web y sistemas de mensajería.

srw-rw-rw- 1 root root 0 ene 15 10:30 /var/run/mysqld/mysqld.sock
🔗

Enlaces duros

Copia del inode (nodo i) que apunta a los mismos datos físicos en disco. A diferencia de los simbólicos, no se rompen si se borra el original porque apuntan directamente a los bloques de datos. No pueden cruzar límites de partición.

(mismo inode 1234567 -rw-r--r-- 2 usuario usuario)

03 Rutas absolutas vs relativas

Cada archivo en Linux tiene una ruta (path) que lo identifica de forma única. Entender la diferencia entre rutas absolutas y relativas es fundamental para navegar el sistema de archivos y escribir scripts correctamente.

Ruta absoluta

/home/usuario/documentos/archivo.txt

Siempre comienza desde / (raíz del sistema). Es la ruta completa e inmutable sin importar dónde te encuentres en el sistema. Es la forma más segura de referenciar archivos en scripts porque no depende del directorio de trabajo actual.

Ruta relativa

../documentos/archivo.txt

Parte de tu ubicación actual. Usa . para referenciar el directorio actual y .. para el directorio padre. Es más corta pero depende del contexto. Es útil para referenciar archivos cercanos en la estructura del proyecto.

SímboloSignificadoEjemplo de uso

~Home del usuario actual (~ = /home/usuario)cd ~ && ls

04 Comandos de navegación esenciales

Estos son los comandos básicos que todo usuario de Linux debe dominar para moverse eficientemente por el sistema de archivos. Cada uno tiene múltiples opciones que permiten personalizar su comportamiento.

pwd

Muestra la ruta completa del directorio de trabajo actual ("Print Working Directory"). Es útil cuando estás perdido en el sistema o necesitas la ruta absoluta para un script.

$ pwd /home/usuario $ cd /etc $ pwd /etc
ls

Lista los archivos y directorios del directorio actual. Es el comando más usado en Linux. Las flags más importantes: -l formato largo, -a incluir ocultos, -la combinación, -lh tamaños legibles.

$ ls -la drwxr-xr-x 3 usuario usuario 4096 . drwxr-xr-x 5 usuario usuario 4096 .. -rw-r--r-- 1 usuario usuario 220 .bashrc -rw-r--r-- 1 usuario usuario 807 document.txt drwxr-xr-x 2 usuario usuario 4096 documentos
cd

Cambia el directorio de trabajo. Sin argumentos regresa al home. Acepta rutas absolutas, relativas y los atajos ~, -, ., ... Es el comando más básico para la navegación.

$ cd /var/log # ir a ruta absoluta $ cd ../etc # ruta relativa al padre $ cd ~ # volver al home $ cd - # volver al directorio anterior
file

Identifica el tipo real de un archivo analizando su contenido (magic numbers), no su extensión. Es especialmente útil cuando la extensión es engañosa o el archivo no tiene extensión.

$ file imagen.png imagen.png: PNG image data, 800x600, 8-bit/color $ file /bin/ls /bin/ls: ELF 64-bit LSB shared object $ file script.sh script.sh: Bourne-Again shell script

📋 Cheat Sheet — Filesystem

/Raíz del sistema de archivos — punto de partida de toda la jerarquía
/homeDirectorios personales de cada usuario — documentos, configuración personal
/etcArchivos de configuración del sistema — passwd, fstab, hosts, shadow
/varDatos variables — logs (/var/log), caché, colas de correo, bases de datos
/usrProgramas y bibliotecas — /usr/bin, /usr/lib, /usr/share, /usr/local
/tmpArchivos temporales — se borran al reiniciar — cualquier usuario puede escribir
/procFilesystem virtual — información del kernel y procesos en tiempo real
/devDispositivos de hardware — /dev/sda, /dev/null, /dev/tty
/binEjecutables esenciales — ls, cp, mv, rm, cat, chmod, mkdir
/bootArchivos de arranque — kernel (vmlinuz), initrd, bootloader (GRUB)
/libBibliotecas compartidas (.so) necesarias por /bin y /sbin
/optSoftware de terceros — aplicaciones grandes como Google Chrome, Steam
pwdPrint Working Directory — muestra directorio actual
ls -laListado detallado con archivos ocultos y permisos completos
cd ~Volver al home del usuario actual
